The Core Challenge: X Region Design

The Problem

The X region must contain a functional splice acceptor (branch point + polypyrimidine tract + AG). But the polypyrimidine tract will be translated when the intron is retained. What amino acids result?

Splice Acceptor Needs

  • Branch point: YUNAY motif
  • PolyY tract: 12+ pyrimidines (C/T)
  • AG dinucleotide: Essential splice site
  • Spacing: 18-40 nt between BP and AG

Translation Constraint

  • No stop codons allowed
  • Avoid proline (CCN codons = kinks)
  • Frame preservation: Length mod 3 = 0
  • Pure pyrimidines limit codon choices

Solution

  • 27 nt X region (9 codons)
  • Ser, Phe, Leu from polyY
  • Branch point adenine encodes Thr (ACT)
  • AG terminus encodes Gln (CAG)
