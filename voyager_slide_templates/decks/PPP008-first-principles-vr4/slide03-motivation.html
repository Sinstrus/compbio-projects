First-Principles Donors Complement the HEK293T Gene-Derived Library

THE QUESTION

Can we cover the full splicing spectrum with predictable, sequence-designed donors instead of relying on natural gene-derived introns?

HEK293T GENE-DERIVED (AVD059–099)

  • 41 donors from retained introns in HEK293T RNA-seq
  • Natural context — donors evolved for their native gene
  • Splicing strength predicted by ML model (log2FC)
  • Variable intronic sequences complicate comparison

Strength: biological relevance. Limitation: confounded by flanking context.

FIRST-PRINCIPLES (AVD100–131)

  • 32 donors designed from U1 snRNA thermodynamic model
  • Identical cassette backbone — only donor varies
  • Splicing strength set by ΔG and H-bond count
  • Clean comparison: same payload, same acceptor, same backbone

Strength: controlled, predictable. Limitation: untested in cells.

Rationale: Running both libraries in parallel lets us (1) validate the thermodynamic model against cell data, (2) identify the optimal splicing window for VHH display, and (3) determine whether synthetic or natural donors produce better VHH-displaying capsids.
