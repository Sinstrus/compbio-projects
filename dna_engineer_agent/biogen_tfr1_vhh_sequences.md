## Sequence Comparison Summary

### Clone A vs Clone B
| Property | Clone A (SEQ ID 1) | Clone B (SEQ ID 5) |
|----------|-------------------|-------------------|
| Length | 112 aa | 127 aa |
| CDR3 Length | 6 aa | 20 aa |
| Framework | IGHV3-like | IGHV3-like |
| C-terminus | ...WGQGTLVTVSS | ...WGQGTLVTVSS |

### Key Structural Notes
- **Clone A:** Shorter CDR3, cryo-EM structure at 2.4Å with hTfR1
- **Clone B:** Extended CDR3 (20 aa), cryo-EM structure at 2.7Å with hTfR1
- Both clones bind apical domain of TfR1
- Both clones are cross-reactive with human, cyno, and mouse TfR1
- Binding does not compete with transferrin
