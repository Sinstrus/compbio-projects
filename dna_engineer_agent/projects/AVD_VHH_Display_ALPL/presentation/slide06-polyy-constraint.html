Polypyrimidine Tract Translation

Pure Pyrimidine Codons (C and T only)

Codon Amino Acid Properties Acceptable?
TTT, TTC Phenylalanine (F) Aromatic, bulky but tolerable YES
TCT, TCC Serine (S) Small, flexible, ideal for linkers YES
CTT, CTC Leucine (L) Hydrophobic, common in proteins YES
CCT, CCC Proline (P) Causes structural kinks - AVOID NO

Branch Point Challenge

Branch point consensus YUNAY contains adenine (A), breaking pure pyrimidine. Solution: Position the A in codon context that gives acceptable amino acid (ACT = Thr).

Design Strategy

Use Leu-Thr-Leu pattern to incorporate branch point A while avoiding Pro (CC dinucleotides). Terminate with CAG (Gln) at splice junction.
