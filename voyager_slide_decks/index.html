VP1 N-Terminal VHH Display Strategy

The VP1 unique region provides an accessible N-terminal site for nanobody insertion without disrupting capsid assembly or genome packaging.

  • VHH3 anti-TfR1 nanobody fused via (G₄S)₂ flexible linker
  • Maintains AAV9 tropism with enhanced CNS transduction
  • Compatible with standard triple-transfection production

Construct Design

MA insertion at VP1 position 1, followed by VHH3 coding sequence and flexible glycine-serine linker before the native VP1 start.

Expected Outcome

60 copies of VHH displayed per capsid (VP1 stoichiometry ~5:1:10). Enhanced BBB transcytosis via TfR1 engagement.

Usage Notes

File Structure
─────────────
  css/
    vygr-base.css          Design tokens, reset, .slide container, common elements
    vygr-content.css       Content slide (standard body layout)
    vygr-title.css         Title/cover slide
    vygr-section.css       Section divider slide
    vygr-table.css         Table-specific styling
    vygr-timeline.css      Timeline/Gantt styling
  templates/
    content.html           Standard content slide
    content-with-subtitle.html   Content with blue or orange subtitle bar
    title-cover.html       Title/cover slide
    section-divider.html   Section divider
    table.html             Table slide
    timeline.html          Timeline/Gantt slide
  assets/
    (13 branding PNGs from vygr_branding_pptx.zip)

Quick Start
───────────
1. Copy a template from templates/ as your starting point.
2. Always include vygr-base.css first, then the template-specific CSS.
3. Replace placeholder text with your content.
4. Open in browser at 100% zoom for pixel-accurate 960×540 preview.

Fonts
─────
Headings: Century Gothic (system font — installed on Voyager machines)
Body:     Calibri (system font)
Fallback chain covers macOS + Linux if needed.

CSS Custom Properties
─────────────────────
All brand colors available as --vygr-* variables.
Override in your HTML via inline style on the .slide element if needed.

Slide Classes
─────────────
.slide                    Base container (960×540, relative positioning)
.slide--content           Standard body slide
.slide--title             Title/cover slide
.slide--section           Section divider
.slide--table             Table variant (add to .slide--content)
.slide--timeline          Timeline/Gantt (standalone)

Header Variants
───────────────
.slide-header             Standard height (75px), medium banner
.slide-header--short      Short header (60px), lowest-level banner

Subtitle Bars
─────────────
.slide-subtitle--blue     Blue gradient strip
.slide-subtitle--orange   Orange gradient strip
